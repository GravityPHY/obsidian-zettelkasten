01 · 哲学根基

什么是卡片盒笔记法

Zettelkasten（德语"卡片盒"）由社会学家 Niklas Luhmann 发展完善。他用这套方法在 40 年间发表了 70 本著作和 400 余篇论文。其核心不是"存储信息"，而是让思想与思想之间产生联结，催生意想不到的洞见。

一张卡片的价值，不在于它本身写了什么，而在于它与其他卡片之间的关系网络。

— Niklas Luhmann 的 Zettelkasten 方法论

Obsidian 是实践 Zettelkasten 的理想工具：本地 Markdown 文件 + 双向链接 + 关系图谱，完美还原了物理卡片盒的连接逻辑，同时突破了纸张的局限。

02 · 笔记分类

三种核心笔记类型

Zettelkasten 的运转依赖三类笔记的协同工作，每种类型有其独特使命。

闪念笔记

Fleeting Notes

随时捕捉的原始想法、灵感片段。不求完整，只求及时。24–48小时内须处理或丢弃。

文献笔记

Literature Notes

阅读书籍/文章/视频后，用自己的语言记录要点。必须注明来源，避免照抄原文。

永久笔记

Permanent Notes

系统的核心。每张只表达一个完整想法，用完整句子写成，可独立阅读，并链接相关笔记。

索引笔记

Index / MOC

主题的入口地图（Map of Content）。聚合某一领域的核心永久笔记，构建导航层级。

06 · 工作流程

日常处理流程

01

捕捉（Capture）

随时将闪念扔进 00-Inbox/，不加工、不整理。可用手机 App 或快捷键。

02

处理（Process）

每天或每周定期清理 Inbox。每条闪念决定：转化为永久笔记，还是删除。

03

连接（Link）

永久笔记写完后，立即找它与其他笔记的关联。这一步是 Zettelkasten 的灵魂所在。

04

涌现（Emerge）

定期在关系图谱中漫游，发现意外的连接。写作时从 MOC 出发，让笔记网络告诉你该写什么。

05

输出（Output）

文章、演讲、项目方案——都从已有笔记中"提炼"，而非从零开始。

08 · 实践原则

Zettelkasten 的黄金法则

⚛️

原子性

每张笔记只讲一件事。如果写完觉得"还需要补充"，就拆成两张。

🗣️

用自己的话

永远不要复制粘贴。用自己的语言重述，才能检验是否真正理解。

🔗

链接优于标签

优先使用 [[双向链接]]，而非 #标签。链接是语义的，标签是分类的。

🚫

不追求完美

不要为"整理"而整理。Zettelkasten 是有机生长的，混乱是正常状态。

♻️

定期复习

随机打开一张旧笔记，看能否建立新的连接。这是系统价值释放的关键。

📝

写给未来的自己

假设读者是六个月后忘记了一切的自己。笔记需要完整、自洽。

09 · Dataview 示例

用 Dataview 查询笔记网络

在 MOC 笔记中嵌入 Dataview 查询，实现动态索引：

DATAVIEW ```dataview
// 列出所有含 #认知科学 标签的永久笔记
TABLE file.ctime AS "创建时间", length(file.outlinks) AS "出链数"
FROM "20-Permanent" AND #认知科学
SORT file.ctime DESC
```
DATAVIEW ```dataview
// 找出孤立笔记（没有任何入链）
LIST WHERE length(file.inlinks) = 0
AND file.folder = "20-Permanent"
```
