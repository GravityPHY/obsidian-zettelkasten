# Obsidian Zettelkasten 模板

一套开箱即用的 Zettelkasten（卡片盒笔记法）Obsidian 仓库模板。

## 目录结构

00-Inbox/        闪念笔记，随时捕捉想法
10-Literature/   文献笔记，读书/文章后整理
20-Permanent/    永久笔记
30-Projects/     进行中的项目
40-Archive/      已完成/归档内容
90-Templates/    笔记模板
95-MOC/          索引地图笔记

## 使用方法

1. 克隆此仓库
2. 用 Obsidian 打开文件夹作为新仓库
3. 安装插件：Templater、Dataview、QuickAdd、Buttons
4. 在 Templater 设置中绑定 Folder Templates：
   - 00-Inbox → 闪念笔记模板
   - 10-Literature → 文献笔记模板
   - 20-Permanent → 永久笔记模板
   - 30-Projects → 项目笔记模板

## 推荐插件

| 插件 | 用途 |
|------|------|
| Templater | 自动填入时间戳、日期 |
| Dataview | 动态查询笔记 |
| QuickAdd | 快速创建永久笔记 |
| Buttons | 闪念笔记一键转化 |

## 工作流

有想法 → 00-Inbox（闪念）
读完内容 → 10-Literature（文献）
加工想法 → 20-Permanent（永久笔记 + 双向链接）
开始项目 → 30-Projects
完成归档 → 40-Archive
主题汇聚 → 95-MOC
